## ۷) گام‌های بعد (فاز AI‑1 — برنامهٔ تأییدشدهٔ کارفرما)
1. `config.local.php`: `TELEFONCHY_WEBSERVICE_TOKEN` (از پنل تلفنچی؛ فقط هاست).
2. جداول: `phone_calls` (کلید `cuid=call_id`)، `call_analysis`، `ai_usage_*` (لاگ درخواست‌ها/سهمیه).
3. `services/telefonchy.php`: کلاینت API — `GET https://telefonchy.com/webservice/v1/calls` (لیست؛ تاریخ‌های شمسی)، `GET .../v1/calls/record?file_id&cuid` (صوت)، `POST .../calls/analysis/request` و `GET .../analysis/show` (تحلیل؛ ۲۰۰/۲۰۲؛ `analysis_status` → `completed|failed`؛ ~۶۰ req/min).
4. صفحهٔ «تماس‌ها» + دکمهٔ «🔄 همگام‌سازی تماس‌ها» (نیازی به cron ندارد؛ بعداً cron اختیاری).
5. پخش صوت با پراکسی سمت سرور + دکمهٔ «ذخیرهٔ آرشیو» در `uploads/calls/` (تصمیم کارفرما: هر دو).
6. **تحلیل خودکار برای همهٔ تماس‌های پاسخ‌داده‌شدهٔ دارای صوت** (تصمیم کارفرما): کلید `ai_analysis_auto` + سقف روزانه `ai_analysis_daily_cap` در تنظیمات؛ توقف خودکار در صورت ۴۰۲/۴۲۹.
7. تطبیق شماره با `crm_customers`/`crm_leads` (موبایل) و ثبت `crm_activities` نوع call.
8. GapGPT (مرحلهٔ بعدی) فقط برای لایهٔ تکمیلی ادمین-ایجنت؛ متن تحلیل منبع اصلی است.
