# ADR-0001: انتخاب استک فنی

- **وضعیت:** پیشنهادی — در انتظار تأیید کارفرما
- **تاریخ:** ۲۰۲۶-۱۱-۰۶

## زمینه
پروژهٔ وب بزرگ و حساس با PHP و دیتابیس SQL برای ساخت اپلیکیشن و سایت لازم است.
مخزن در ابتدا خالی بود؛ هیچ استک قبلی تحمیل نشده است.

## تصمیم پیشنهادی
- PHP 8.3، فریم‌ورک **Laravel 11**
- MySQL 8 / MariaDB 10.11 (InnoDB, utf8mb4)
- Redis برای cache/queue (اختیاری)
- Nginx + PHP-FPM + Docker Compose برای استقرار تکرارپذیر

## گزینه‌های ردشده (فعلاً)
- **PHP خالص بدون فریم‌ورک:** فقط اگر تیم به فریم‌ورک عادت ندارد؛ هزینهٔ نگهداری و ریسک امنیتی بالاتر است.
- **Symfony:** انتخاب عالی برای سیستم‌های بسیار enterprise؛ سنگین‌تر برای شروع سریع.
- **PostgreSQL:** اگر دادهٔ جغرافیایی یا JSONB سنگین دارید جایگزین مناسب MySQL است؛ با تأیید شما اعمال می‌شود.

## عواقب
- سرعت توسعه و امنیت پیش‌فرض Laravel (Eloquent, CSRF, validation) کاهش ریسک پروژهٔ حساس را ممکن می‌کند.
- نیاز به Composer و محیط PHP 8.2+ در سرور/لوکال شما.
- در صورت تغییر نظر (مثلاً PHP خالص)، این ADR به‌روزرسانی و کد بر همان اساس چیده می‌شود.
