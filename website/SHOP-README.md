# فروشگاه — وضعیت بررسی

نسخهٔ واردشده از فایل ارسالی، کد موجود فروشگاه است، نه اعلام آمادگی فروش. راهنمای قدیمی که جایگزینی `config.php` و اجرای schema را بدون بررسی توصیه می‌کرد کنار گذاشته شد. **کانفیگ خصوصی، بکاپ و داده‌های واقعی در Git نیستند و نباید با بسته‌ها جایگزین شوند.**

فروشگاه در مسیر `/shop/` است ولی به `/account/`, `/cart/`, `/checkout/`, `/includes/shop/` و بخش‌هایی از `/admin/` و فایل‌های مشترک روت وابسته است. توضیح مسیر، نقشهٔ اتصال و خطرهای شناخته‌شده در `docs/WEBSITE_HANDOFF.md` در ریشهٔ مخزن است. اتصال CRM، درگاه بانکی و تست MySQL/هاست در این مرحله انجام نشده‌اند. جدول‌های SQL صرفاً برای بررسی هستند و بدون بکاپ و بررسی دیتابیس فعال اجرا نشوند.
